# PUYA Beach Villa — เว็บไซต์พูลวิลล่าริมทะเล อ.เทพา จ.สงขลา

เว็บไซต์พรีเซนต์ที่พักภาษาไทย พัฒนาด้วย Next.js + Tailwind CSS — deploy บน Vercel

## ช่องทางติดต่อ
- [Facebook](https://www.facebook.com/PUYA.Beach.Villa)
- [TikTok](https://www.tiktok.com/@puya.beach.villa)
- Line: `@puyabeach`

## วิธีรันในเครื่อง
```bash
npm install
npm run dev   # เปิด http://localhost:3000
```

## โครงสร้างเว็บ (one-page)
1. Hero — ภาพที่พัก + ปุ่มติดต่อ
2. ที่พัก — พูลวิลล่า 1 และ 2 (ตกแต่งเหมือนกัน)
3. แกลเลอรี
4. ติดต่อเรา — Google Maps + โซเชียล
